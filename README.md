# Rogue Platformer

这是一个使用 Godot 4 制作的原创 2D 横版动作肉鸽原型。目前已经完成移动、战斗、随机房间、一局构筑与第一轮内容扩展。

## 当前玩法

- 移动、二段跳、冲刺和近战攻击
- 带生命值、受伤无敌帧、击退和死亡反馈的战斗
- 会巡逻、追击和近身攻击的近战敌人
- 会保持距离并发射弹丸的远程敌人
- 从五种手工布局中随机排列一条五房间路线
- 清理房间后，从三项不重复强化中选择一项
- 强化在本局内保留；死亡后清空强化并重新生成路线
- 月弧长剑、影织双刃和坠星巨刃拥有不同伤害、攻速与攻击距离
- 每种武器带有独立主动技能和冷却时间
- 一局依次包含普通战斗、宝箱、精英、商店与首领遭遇
- 胜利或死亡会结算局外星屑；武器解锁和当前选择会自动保存

## 操作

- `A / D` 或左右方向键：移动
- `W`、上方向键或空格：跳跃；离地后可再跳一次
- `J`：攻击
- `K`：冲刺
- `L`：释放当前武器的主动技能
- `Q`：在已解锁武器之间切换
- `E`：开启宝箱；在商店中离开
- `1 / 2 / 3`：选择房间强化
- `R`：随时重新开局

## 打开项目

1. 使用 Godot 4.7.2 或兼容的 Godot 4 稳定版导入 `project.godot`。
2. 在编辑器中按 `F6` 或 `F5` 运行。

## 项目结构

- `scenes/`：Godot 场景
- `scripts/`：角色、敌人、房间与一局流程逻辑
- `assets/`：项目内角色视觉资源
- `tests/`：动画、攻击连按、战斗、一局结构与内容扩展的自动测试
- `tools/`：角色帧构建工具
- `docs/`：开发路线

详细进度见 `docs/ROADMAP.md`。

局外进度默认保存在 Godot 用户数据目录下的 `rogue_progress.json`。
