# Rogue Platformer

这是一个使用 Godot 4 制作的原创 2D 横版动作肉鸽原型。目前已经完成移动、战斗、随机房间、一局构筑与第一轮内容扩展。

## 当前玩法

- 移动、二段跳、冲刺和近战攻击
- 带生命值、受伤无敌帧、击退和死亡反馈的战斗
- 会巡逻、追击和近身攻击的近战敌人
- 会保持距离并发射弹丸的远程敌人
- 从十二种手工布局中生成一条二十房间路线，并显示可复现的本局随机种子
- 第 5、10、15、20 房为阶段首领；其余房间包含战斗、宝藏、精英、商店、事件、挑战和风险宝箱
- 首领拥有突进、弹幕和震地三种预警招式，并会在 70% / 35% 生命进入新阶段
- 清理房间后，从三项不重复强化中选择一项
- 强化在本局内保留；死亡后清空强化并重新生成路线
- 月弧长剑、影织双刃和坠星巨刃拥有不同伤害、攻速与攻击距离
- 每种武器带有独立主动技能和冷却时间
- 一局依次包含普通战斗、宝箱、精英、商店与首领遭遇
- 胜利或死亡会结算局外星屑；武器解锁和当前选择会自动保存
- 自动记录最近 60 次路线尝试的房间耗时、受伤/死亡来源、首领击杀时间、强化选择率与武器通关率，供后续平衡调整
- 难度采用房间战斗预算和六级行为递进：逐步增加追层、连击与远程齐射，基础生命/伤害/速度只做有上限的温和成长

## 操作

- `A / D` 或左右方向键：移动
- `空格`：跳跃；离地后可再跳一次
- `W / S` 或上下方向键 + `J`：上劈 / 下劈
- `J`：攻击
- `K`：冲刺
- `L`：释放当前武器的主动技能
- `Q`：在已解锁武器之间切换
- `E`：开启宝箱；在商店中离开
- `1 / 2 / 3`：选择房间强化
- `R`：随时重新开局

Xbox 手柄默认使用：左摇杆/十字键移动与菜单导航，A 跳跃/确认，X 攻击，B 冲刺/返回，Y 技能，RB 互动/开宝箱，LB 切换武器，Menu 暂停，View 重开。选牌时可用 X / Y / B 直接选择第 1 / 2 / 3 张牌，也可移动焦点后按 A 确认；界面提示会随最近使用的键盘或手柄自动切换。

## 打开项目

1. 使用 Godot 4.7.2 或兼容的 Godot 4 稳定版导入 `project.godot`。
2. 在编辑器中按 `F6` 或 `F5` 运行。

## 导出 Windows 测试包

1. 安装与 Godot 4.7.2 匹配的 Windows x86_64 发布模板。
2. 在项目根目录运行 `powershell -ExecutionPolicy Bypass -File .\tools\verify_windows_build.ps1`。
3. 验证通过的 EXE 与 PCK 位于 `build/windows-verify/`；脚本会自动隐藏启动 EXE，并检查运行日志。

完整人工验收项目见 `docs/WINDOWS_RELEASE_CHECKLIST.md`。

## 项目结构

- `scenes/`：Godot 场景
- `scripts/`：角色、敌人、房间与一局流程逻辑
- `assets/`：项目内角色视觉资源
- `tests/`：动画、攻击连按、战斗、一局结构与内容扩展的自动测试
- `tools/`：角色帧构建工具
- `docs/`：开发路线

详细进度见 `docs/ROADMAP.md`。

局外进度默认保存在 Godot 用户数据目录下的 `rogue_progress.json`，平衡统计保存在同目录的 `run_telemetry.json`。
