# 产品体验规则

更新时间：2026-09-07
状态：首次游玩、死亡复盘、房间边界继续、统一奖励层和显示辅助已实现；后续工作由真实试玩决定。

本文件记录玩家流程中不能轻易改乱的行为契约。项目优先级统一在 [ROADMAP.md](ROADMAP.md) 维护。

## 当前玩家流程

| 场景 | 当前行为 |
| --- | --- |
| 标题页 | 有有效继续档时优先显示“继续旅程”；也可开启新局、设置或退出 |
| 新局 | 先选择难度，再生成新的种子、20 房布局序列和遭遇序列 |
| 第一局 | 仅在启用真实存档、尚未通关且进入第一房战斗时显示移动/跳跃/攻击非阻断引导 |
| 清房 | 普通战斗完成后生成月蚀之门；玩家走近并按 `E` / RB 后进入强化选择 |
| 特殊房 | 商店和事件直接选择后进入下一房；宝箱先结算；风险宝箱先触发伏兵再结算 |
| 死亡 | 立即扣除一条命、结束当前路线并清除继续档；复盘层保持暂停，等待玩家明确选择 |
| 再次挑战 | 尚有命数时以剩余命数开启新路线；命数为零时返回难度选择并从三条命重新开始 |
| 胜利 | 结算星屑和解锁，清除继续档；玩家选择“再来一局”或“返回标题” |

## 中途继续契约

继续档路径：`user://run_continue.json`。

### 写入时机

- 房间加载完成：战斗、宝箱、商店或事件。
- 清房传送门出现。
- 强化、商店或事件选择界面出现。
- 从暂停菜单返回标题前。

### 不写入时机

- 战斗进行到一半；重新进入时从当前房门口重打。
- 死亡或通关后。
- 尚未选定难度的标题流程。

### 恢复内容

- 种子、随机数状态、难度、命数、金币、星屑、武器、生命和强化层数。
- 20 房布局与遭遇序列、当前房数据和当前流程阶段。
- 强化、商店、事件处于选择状态时，恢复原有选项，不重新抽取。

继续档、进度、设置与遥测均使用临时文件写入、主档替换和 `.bak` 恢复。修改字段时必须同时更新版本验证与恢复测试。

## 事件房现状

当前固定三项选择均包含收益与代价：

| 选项 | 收益 | 代价 |
| --- | --- | --- |
| 月泉献礼 | 恢复至多 40 生命 | 金币 -8，最低扣到 0 |
| 搜寻遗物 | 金币 +28 | 受到 16 点伤害，至少保留 1 生命 |
| 星语契约 | 星屑 +3，并恢复至多 12 生命 | 本局最大生命 -10 |

结算提示必须展示实际变化，例如满血时显示“生命已满”，不能展示未发生的承诺值。

## 输入与显示辅助

- 键鼠和 Xbox 提示根据最近使用的设备切换。
- 菜单、难度卡、奖励卡、死亡和胜利页必须始终有可见焦点。
- 已支持减弱闪光/镜头震动、大号字、高对比、色觉辅助和 HUD 90%/100%/110% 缩放。
- 显示辅助必须可持久化、重复应用不累乘，且不改变游戏数值。

## 试玩观察重点

1. 玩家能否在没有口头指导时开始第一局。
2. 是否能区分空挥和命中，并理解冲刺取消。
3. 是否看懂事件卡的收益与代价。
4. 死亡后是否理解“命数”和“新路线”的关系。
5. 关闭游戏再启动后，是否理解“继续旅程”会从当前房开头恢复。
6. UI 提示是否遮挡战斗，键盘和手柄提示是否与实际输入一致。

## 后续候选

这些不是当前承诺，只有试玩证据支持时才进入路线图：

- 冲刺、技能、上劈和下劈的渐进式非阻断提示。
- 按章节变化的事件池和影响下一房的事件结果。
- 字体回退与多语言资源结构。
- 多存档槽和更明确的失败成长反馈。
