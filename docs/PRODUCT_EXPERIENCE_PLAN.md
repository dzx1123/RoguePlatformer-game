# 产品化体验计划

状态：0.4.1 已补引导、复盘、继续；商店/胜利页与无障碍仍在 P7。  
相关清单：[UI_POLISH_CHECKLIST.md](UI_POLISH_CHECKLIST.md)、[ROADMAP.md](ROADMAP.md) P7。

## 第一局和失败（已做 / 还差）

新玩家会卡的地方，原先是 P7 最大的洞。

| 项 | 0.4.1 | 还差 |
| --- | --- | --- |
| 第一房引导 | 非阻断顶栏：移动、跳跃、攻击；做完即消失 | 没有独立教学房；没有上劈/下劈/冲刺/技能的分步 |
| 死亡复盘 | 死后展示死因、房间、承伤、来源、剩余命数 | 没有「下一局可以怎么打」的具体建议 |
| 中途继续 | 房间边界写入 `user://run_continue.json`；标题页「继续第 N 房」 | 战斗中途退出会重打当前房；没有多存档槽 |
| 失败结算 | 仍结算星屑并可能解锁武器 | 标题页局外进度已有，失败瞬间除复盘外没有成长感动画 |

引导只在 `save_enabled` 且 `runs_completed == 0` 且第一房战斗时出现。自动测试默认关存档，不会被挡住。

死亡复盘不阻断原有命数逻辑：约 1.05 秒后仍按剩余命数重开，或回到难度选择。

## 中途继续规则（写死，避免以后改乱）

**会写入的时机**

- 房间加载完成（战斗、宝箱、商店、事件）
- 清房传送门出现
- 三选一强化出现

**不会写入的时机**

- 战斗进行到一半（退出后从本房门口重来，可接受）
- 死亡（本局已结束，清掉继续档）
- 通关
- 标题页点「开始冒险」并选定难度（新开局覆盖）

**恢复内容**

- 种子、难度、命数、金币、星屑、武器、强化层数、生命/生命上限
- 20 房序列、当前房布局、当前流程阶段（含选牌/商店/事件选项）

暂停「返回主菜单」会先写一份继续档。

## 事件房取舍（已做）

不再是三张纯奖励。当前固定池：

| 选项 | 好处 | 代价 |
| --- | --- | --- |
| 月泉献礼 | 恢复 40 生命 | 失去 8 金币（不足则扣到 0） |
| 搜寻遗物 | 获得 28 金币 | 受到 16 点伤害（至少留 1 血） |
| 星语契约 | 3 星屑并恢复 12 生命 | 本局最大生命 -10 |

后续（未做）：

- [ ] 按章节换事件池，不要 20 房重复同一组
- [ ] 增加会改变下一房遭遇的选项（例如下一房必出精英）
- [ ] 商店/事件/胜利页套入与选牌相同的奖励层动效

## 建议的试玩观察点

给别人 zip 时优先看这些，而不是先问「要不要加图鉴」：

1. 空砍和砍中是否分得清。
2. 砍中后立刻按冲刺是否能取消。
3. 死掉后能否看懂是谁、在哪一房。
4. 关掉游戏再打开，标题页能否继续未完成路线。
5. 事件三张牌是否看得出代价。
6. 第一次开局顶栏引导会不会挡住战斗（不应挡住）。
