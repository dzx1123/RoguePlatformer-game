# 音乐与音效规范

更新时间：2026-09-07
状态：核心音乐、角色语音、战斗与世界事件音效已接入；后续仅做实机混音复核或素材驱动替换。

许可证与生成方式见 `assets/audio/LICENSES.md`。

## 当前结构

| 层 | 总线 | 当前实现 |
| --- | --- | --- |
| 音乐 | `Music` | 原创合成循环：标题 `cover.wav`、探索 `explore.wav`、首领 `boss.wav` |
| 战斗与世界 | `SFX` | 原创刀风、刃击、技能、脚步、落地、UI、卡片、宝箱、传送门和敌人事件；击败冲击保留已登记 CC0 层 |
| 角色与敌人短呼 | `Voice` | 原创合成的玩家攻击/技能/跳跃/受伤/倒地，以及史莱姆和哥布林攻击/受伤/倒地短呼 |

混音顺序保持为：角色短呼 > 命中刃击 > 空挥刀风。人声播放时音乐短暂压低；设置页分别控制主音量、音乐、音效和语音。

## 音乐状态

| 状态 | 使用场景 | 当前轨道 |
| --- | --- | --- |
| `MENU` | 标题、难度、死亡复盘、胜利结算 | `cover.wav` |
| `EXPLORE` | 选牌、商店、事件、传送门 | `explore.wav` |
| `COMBAT` | 普通战斗与伏兵 | `explore.wav`，提高运行时强度 |
| `BOSS` | 首领战 | `boss.wav` |

状态切换由 `soundscape.gd` 交叉淡入淡出。正式替换音乐时保持状态入口不变，只换稳定资源路径和混音参数。

## 事件覆盖

| 事件组 | 当前声音 | 规则 |
| --- | --- | --- |
| 普攻 | 原创短呼 + 轻刀风 | 每次起手可播；刀风不得盖住命中 |
| 命中 | 清脆刃击 + 延迟敌人痛呼 | 先听到命中，再听到对象反应 |
| 三武器技能 | 长剑晶鸣、双刃连切、巨刃低沉冲击 | 不通过修改判定制造音色差异 |
| 跳跃/冲刺 | 轻量程序动作层 + 玩家短呼 | 不与命中争抢响度 |
| 落地/脚步 | 原创短采样 | 由动作接触节奏门控，不连续叠播 |
| UI/卡片/拒绝 | 独立原创短采样 | 购买失败必须与成功确认可区分 |
| 宝箱/传送门 | 独立原创采样 | 单次播放，偏音乐感但不盖过提示 |
| 敌人攻击/受伤/死亡 | 按史莱姆、哥布林和首领区分 | 首领允许更低沉，不增加无意义叠层 |

- `tools/render_designed_audio.gd`：重新生成原创音效。
- `tools/render_bgm.gd`：重新生成三轨音乐。

## 修改流程

1. 确认授权，将文件放入稳定的音频子目录并更新 `assets/audio/LICENSES.md`。
2. 只在 `soundscape.gd` 调整资源数组、音量、音高或淡入淡出，不修改玩法触发时机。
3. 挥刀采样宜短于 `0.8` 秒，死亡层宜短于 `1.5` 秒。
4. 运行 `soundscape_smoke.gd` 与 `combat_audio_duration_smoke.gd`。
5. 用耳机实际检查空挥/命中、三武器技能、脚步、宝箱、传送门、受伤和死亡。
6. 再检查四个音量设置跨重启保持。
