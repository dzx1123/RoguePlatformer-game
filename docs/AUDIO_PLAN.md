# 音乐与音效计划

状态：事件表和程序占位已接通，正式曲与高质量 Foley 仍缺。  
许可证登记：`assets/audio/LICENSES.md`

## 难点拆开

难的是两头：

1. **内容**：没有主题曲、房间/首领分轨、也没有完整 Foley 包。
2. **设计**：什么时候响、谁最大声、同一刀不要叠三次、三把武器要听得出差别。

代码侧可以做第 2 头，以及把第 1 头接到现有总线。作曲和录音需要另供素材。

## 三层结构（保持）

| 层 | 总线 | 现状 |
| --- | --- | --- |
| 音乐 | Music | `soundscape.gd` 正弦波 4 小节月夜氛围，按状态改强度 |
| 战斗/世界音效 | SFX | CC0 挥刀、命中、技能、史莱姆爆裂 + 程序短音 |
| 角色语音 | Voice | 同一套少年声：攻击、技能、受伤、死亡；连砍隔一刀喊一次 |

语音播放时音乐会压到约 72%。设置里已有主音量 / 音乐 / 音效 / 语音分轨。

## 音乐状态

| 状态 | 何时 | 听感目标 |
| --- | --- | --- |
| MENU | 标题、难度、命数耗尽、通关结算、死亡复盘期间 | 更静、更慢 |
| EXPLORE | 选牌、商店、事件、传送门等非战斗 | 现有垫底 |
| COMBAT | 清房战斗、伏兵 | 垫底略响，加很轻的脉动 |
| BOSS | 首领战且战斗进行中 | 更低的根音、更密的钟 |

正式曲子到位后，用淡入淡出切这四层，不要硬切。触发点继续走 `_update_music_state()`，只换播放器里的 stream。

## 版权策略（不变）

- 不要混入未核授权的网盘/拆包音频

## 接入正式素材的步骤

1. 文件放进 `assets/audio/` 对应子目录，文件名稳定（`play_*` 只 preload 路径）。
2. 时长约束参考 `tests/combat_audio_duration_smoke.gd`：挥刀宜短于 0.8 秒，死亡层宜短于 1.5 秒。
3. 只改 `soundscape.gd` 的数组和音量/音高，不改触发。
4. 跑 `tests/soundscape_smoke.gd` 与 `tests/combat_audio_duration_smoke.gd`。
5. 耳机听：空挥、实砍、技能、开箱、进门、受伤。
