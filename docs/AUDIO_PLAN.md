# 音乐与音效计划

状态：封面 / 普通房 / 首领三轨循环已接入；音效按挥砍让路、先叮后叫分层。  
许可证登记：`assets/audio/LICENSES.md`

## 难点拆开

难的是两头：

1. **内容**：没有主题曲、房间/首领分轨、也没有完整 Foley 包。
2. **设计**：什么时候响、谁最大声、同一刀不要叠三次、三把武器要听得出差别。

代码侧可以做第 2 头，以及把第 1 头接到现有总线。作曲和录音需要另供素材。

## 三层结构（保持）

| 层 | 总线 | 现状 |
| --- | --- | --- |
| 音乐 | Music | 原创循环：封面 `cover.wav`、普通房 `explore.wav`、首领 `boss.wav` |
| 战斗/世界音效 | SFX | 自制刀风 / 刃击 / 施法 / 撕咬 / 喷吐；击败层仍用 CC0 血肉 |
| 角色语音 | Voice | 自制短呼（hya / hup），攻击、技能、跳跃、受伤、倒地 |

混音阶梯（写入 wav 峰值，再由 `soundscape.gd` 的 MIX_*_DB 微调）：**人声 > 刃击 > 刀风**。空挥不再叠刀片采样。语音播放时音乐会压到约 72%。设置里已有主音量 / 音乐 / 音效 / 语音分轨。

## 音乐状态

| 状态 | 何时 | 听感目标 |
| --- | --- | --- |
| MENU | 标题、难度、命数耗尽、通关结算、死亡复盘期间 | 封面曲：慢、疏、钟 |
| EXPLORE | 选牌、商店、事件、传送门等非战斗 | 走廊曲：同调、带脚步脉动 |
| COMBAT | 清房战斗、伏兵 | 走廊曲略抬 |
| BOSS | 首领战且战斗进行中 | 首领曲：更低、心跳、更密 |

正式曲子到位后，用淡入淡出切这四层，不要硬切。触发点继续走 `_update_music_state()`，只换播放器里的 stream。

## 音频事件表

「采样」列：已有文件 / 程序占位 / 仍缺。  
替换原则：改 `soundscape.gd` 里对应数组或 `play_*`，不要改 `main.gd` / `player.gd` 的触发时机。

| 事件 | 触发 | 总线 | 现状 | 音量关系 | 能否叠 |
| --- | --- | --- | --- | --- | --- |
| 空挥 | 普攻起手 | SFX | 自制刀风，单层 | 明显低于人声和命中 | 可，短 |
| 命中 | 攻击/技能打中敌人 | SFX | 清脆叮一声 + 怪物短痛呼 | 叮轻于人声；痛呼像 DNF 哥布林被打 | 可，但命中应盖过挥刀 |
| 技能释放 | 技能起手 | SFX + Voice | 自制晶鸣 + 长呼 | 音效低于人声、高于空挥 | 技能喊声每次都播 |
| 攻击喊声 | 普攻起手 | Voice | 自制短 hyah，每刀一次 | 战斗里最响的角色层 | 池内轮换，不截断上一句 |
| 冲刺 | 冲刺起手 | SFX | 程序风声 | 中等偏轻 | 否 |
| 跳跃 | 起跳 | SFX | 程序起跳音，不再跟人声叠 | 轻 | 否 |
| 落地 | 离地后落地 | SFX | 程序占位 | 轻于命中 | 否 |
| 脚步 | 跑步接触帧（每 4 帧一拍） | SFX | 程序占位 | 最轻之一 | 否，由节奏门控 |
| 开箱 | 宝箱打开 | SFX | 程序占位 | 中等 | 否 |
| 传送门 | 确认进入月蚀之门 | SFX | 程序占位 | 中等偏音乐感 | 否 |
| UI 确认 | 选牌/购买 | SFX | 程序占位 | 轻、干净 | 否 |
| 受伤喊声 | 玩家扣血 | Voice | 已有 | 低于死亡 | 可 |
| 死亡喊声 | 玩家死亡 | Voice | 已有 | 语音层最重 | 否 |
| 敌人攻击喊 | 出手起手 | SFX | 哥布林吠叫 / 史莱姆咕哝 | 能听清，低于玩家人声 | 可 |
| 敌人撕咬 | 近战判定 | SFX | 下颌咬合 | 低于攻击喊 | 可 |
| 敌人 spit | 远程出手 | SFX | 蓄力气流 + 湿爆 | 轻于撕咬 | 可 |
| 敌人挨打 | 被玩家打中 | SFX → Voice | 先清脆叮，约 70ms 后再痛呼 | 叮轻于人声；痛呼错开，不叠成一团 | 可 |
| 敌人死亡 | 击败 | SFX | 血肉/史莱姆/碎裂三层 | 接近玩家命中 | 首领更低更沉 |

仍缺、需要采样或明确放弃的：

| 事件 | 建议 | 优先级 |
| --- | --- | --- |
| 菜单点击 / 返回 | 短而干净的 UI | 中 |
| 选牌出示 | 与 UI 确认区分开的「翻开」 | 中 |
| 商店购买成功 / 金币不足 | 两个短音 | 中 |
| 三武器技能音色差 | 长剑清脆、双刃连切、巨剑低沉 | 高（有采样再换，先不要改判定） |
| 房间探索 BGM loop | 32–64 小节可循环 | 高（发行听感） |
| 战斗 BGM loop | 可叠在探索之上或替换 | 高 |
| 首领 BGM | 独立或探索的低压变体 | 高 |
| 标题主题 | 可与探索同根音 | 中 |
| 陷阱预警 | 地面符文脉冲时 | 中 |
| 首领阶段切换 | 短刺耳或钟声，受「减弱效果」约束 | 中 |

## 版权策略（不变）

- 战斗挥砍、命中、角色短呼使用 `assets/audio/designed/` 原创合成，写入 `assets/audio/LICENSES.md`
- 击败层仍可用已登记的 CC0 血肉采样
- 不要混入未核授权的网盘/拆包音频，也不要使用任天堂录音

## 接入正式素材的步骤

1. 文件放进 `assets/audio/` 对应子目录，文件名稳定（`play_*` 只 preload 路径）。
2. 时长约束参考 `tests/combat_audio_duration_smoke.gd`：挥刀宜短于 0.8 秒，死亡层宜短于 1.5 秒。
3. 只改 `soundscape.gd` 的数组和音量/音高，不改触发。
4. 跑 `tests/soundscape_smoke.gd` 与 `tests/combat_audio_duration_smoke.gd`。
5. 耳机听：空挥、实砍、技能、开箱、进门、受伤。
