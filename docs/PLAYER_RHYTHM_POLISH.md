# 人物动作与操作衔接打磨 · 2026-09-22

适用第一章、第二章共用的 RoguePlayer。沿用人物、武器、关卡、UI、技能伤害与冷却配置。

## 已修正的问题

- 起跑前 0.10 秒原本仍显示站姿：现在首步立即使用跑步帧，仅对身体前倾做过渡。
- 急停和转身共用普通加速度，回身拖沓：地面制动 3400、反向加速度 3600，最高跑速和空中加速度保持原值。
- 普攻、技能、冲刺按早一点就丢失：增加 0.18 秒单动作缓存，最后一次按键优先，不绕过冷却、出招阶段或冲刺取消条件；按住普攻仍只出一招。缓存保存出招方向与上下斩选择，只有动作实际启动才改变朝向。
- 命中停顿期间丢输入、角色变换还在移动：停顿期间接收缓存，但冻结动作计时与人物姿势。
- 跑动收招后额外定格 0.065–0.11 秒：移动时立即接回步态，空中接回跳跃姿势，站定时保留收招姿势。
- 技能启动瞬间直接改写水平速度：改由现有加速度衔接技能突进，保留各武器原有突进曲线。
- 增加 0.12 秒落地跳跃预输入与 0.09 秒离台跳跃容错。离台容错不消耗空中跳跃；穿台单独处理。
- 两章通过 combat_hit_feedback.gd 共用命中停顿。双刀普攻/技能 33/32 ms、月剑 50/72 ms、大剑 65/85 ms，保留原首领加成与降低特效选项。
- 第二章四类熔炉敌人接入实际停顿处理，避免只暂停玩家却让敌人继续移动。
- 去除冲刺时额外硬编码的单手剑残影层；世界空间残影保留并复制当前武器贴图、旋转及脚底校准，采样发生在本帧姿势更新后。
- 死亡、复活、禁用操作及第二章暂停/选牌时清空待执行输入，避免菜单关闭后突然出招。
