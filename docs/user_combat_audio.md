# 用户提供的刀剑音效

- `flesh_cut_user.wav`：来自“刀剑刺中出血；刀剑砍到身体，流血了；刀剑砍杀音效；挥刀劈砍音_爱给网_aigei_com.mp3”。刀剑实际造成肉身伤害时播放，空挥不触发；史莱姆保留原接触音。替换原通用命中声，不额外叠加一层。
- `greatsword_swing_user.wav`：来自“60大剑挥舞_爱给网_aigei_com.mp3”。大剑普通攻击、空中攻击和大剑技能挥舞使用；单手剑、双刀仍使用轻挥音。大剑技能保留原特效音并降低 3 dB。
- 两段 WAV 均为单声道、16 位 PCM；去除头尾静音，添加 3 ms 起音及 25 ms 尾部淡出。肉身命中长约 0.653 秒、峰值 -9 dBFS；大剑挥舞长约 0.589 秒、峰值 -14 dBFS，另受现有 SFX 通道音量控制。
- 命中声音以 80 ms 为最小间隔合并，防止一击多怪时反复重启；挥舞尾音不会被命中强制截断。连续攻击各自重新触发挥舞，不累积多个挥舞播放器。

复现处理：先在 Godot 运行 `tools/decode_user_combat_audio.gd`，再运行 `tools/prepare_user_combat_audio.py`。解码脚本依赖用户下载目录中的原 MP3；游戏运行只依赖项目内 WAV。

验证：`tests/user_combat_audio_smoke.gd` 检查武器路由、空挥、命中、史莱姆、技能、群体命中限频、音频时长和峰值。自动化验证不代替游戏内最终听感确认。
