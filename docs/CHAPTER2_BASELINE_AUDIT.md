## 逐房推进顺序

1. **入口与操作基础**：本轮完成修复及回归。保留最小移动测试，防止再次出现“场景打开但不能动”。
2. **第 21–25 房实战**：按普通伤害验证阶梯练习、热区绕行、接近投掷者、两种冷却仪式结果和首次强化；发现问题时同步修改布局或遭遇，先形成可复用的验收标准。
3. **第 26–35 房内容**：守卫与甲虫教学、混合战斗、高处宝箱、代价事件、双波战斗、试炼、商店；逐项检查敌人落脚点与平台路线。
4. **第 36–40 房收尾**：暗场可读性、两条支路、三敌组合、补给及首领正常伤害完整战斗。
5. **全章复查与交付**：三武器各完成一轮，退出续玩、死亡重试、完成后新开、手柄和画面设置；之后处理动画音效和正式跨章规则。

后四步尚未标为完成。自动化快速清敌仅证明流程和奖励逻辑，不证明战斗平衡或完整人工通关。

## 重跑方式

在项目根目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File tests/run_chapter2_audit.ps1`。共 15 项检查，包含真实物理通行，耗时比纯逻辑检查长。每项要求正常退出、出现对应 PASS 且无 SCRIPT ERROR；不能仅凭引擎退出码判定成功。结果位于 `test_output/chapter2_audit.json`，明细位于 `test_output/audit_*.log`。测试存档与日志留在本项目目录，控制测试的改键只在内存中进行。
