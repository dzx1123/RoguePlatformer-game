# 两章连续旅程接入

更新：2026-11-21。

## 正式路线

第一章最后房间完成后直接进入第 21 房，继承种子、轮次、武器、强化、生命及上限、金币、难度、命数和本局星屑。两章共用 `user://run_continue.json`。跨章时原子写入第 21 房检查点，标题页「继续旅程」按当前房间恢复。旧版正式第二章存档可迁入同一个槽。第二章沿用同一遥测对象，重新加载时从持久化数据恢复。

第二章正式路线不允许 R/F2 免费回血重试。死亡返回 Main 的现有失败回顾，扣除一条命，结算失败所得，按第一章规则从第一章重开。命数耗尽后重新选难度。完成第 40 房后才进入 Main 的整局胜利结算。重复调用胜利结算不会再次入账。选择「开启新局」并确认难度后，新旅程会替换共用继续档中的上一局进度。

难度使用第一章 CombatBudget 的末段倍率调整第二章敌人生命和攻击，包括投掷物；环境热区维持固定伤害。整章武器平衡仍需实战验证。

## 开发入口

标题页右下角的「第二章测试」每次直接进入第 21 房。测试会话的检查点仅在内存中保存，战斗失败可在本次会话重试。若已保存正式进度，返回标题后可通过「继续旅程」恢复。

## UI

两章共用紧凑战斗 HUD、暂停、设置、构筑总览和奖励卡。战斗显示当前房名和 40 房进度，最终胜利和死亡回顾沿用共用界面。

## 验证

`chapter2_campaign_smoke` 覆盖真实场景切换、跨章状态继承、入场后移动、JSON 检查点重建、困难敌人生命倍率、正式路线重试限制、死亡扣命后重开第一章和整局结算。`campaign_continue_migration_smoke` 覆盖共用继续档、旧档迁移和损坏恢复。

2026-09-18 的跨章原型曾以 `build/campaign-connected/EmberForge.exe` 和导出 PCK 验证，HUD 留档见 `test_output/chapter2_campaign_hud.png`。测试使用快速击败首领。四十房人工连玩，以及应用在写入终态与局外结算之间被强制关闭后的恢复，仍待验证。
