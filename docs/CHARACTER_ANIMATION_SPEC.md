# 角色动作资产规范

本规范用于约束主角及后续人形角色的帧画布、锚点、武器和披风分层。新增或替换动作帧时，必须同时通过 `tests/character_frame_spec_smoke.gd` 与 `tests/animation_motion_audit.gd`。

## 1. 主画布与坐标

- 主角完整姿势帧统一为 `640 × 416` RGBA PNG，不允许混用裁切后的可变尺寸。
- 逻辑原点位于画布中心 `(320, 208)`；运行时基础缩放为 `0.22`，`Sprite2D` 基础位置为 `(0, -15)`。
- 地面动作的可见脚底基线为源图 `Y=402 ± 1 px`。八帧跑步循环的脚底跨度不得超过 `2 px`，运行时补偿后的脚底漂移不得超过 `1.25 px`。
- 主体水平锚点以躯干中心为准。跑步循环不能通过每帧大幅左右裁切来伪造移动，身体锚点的运行时漂移不得超过 `0.5 px`。
- 常规帧四周保留至少 `4 px` 透明安全区。允许上挑剑尖少量进入顶部安全区，但外沿非透明像素总量必须低于自动测试阈值，且不得出现整条白边或不透明底色。

## 2. 动作最小帧组

| 状态 | 最小帧/姿势 | 设计要求 |
| --- | ---: | --- |
| 待机 | 1 + 程序化呼吸 | 重心稳定，披风只做低幅摆动 |
| 跑步 | 8 | 接触、下沉、经过、腾空四阶段左右脚各一轮 |
| 起跳/上升/下落/落地 | 4 | 起跳压缩、空中收腿、下落伸展、落地缓冲分开 |
| 普攻 | 4 | 蓄力、命中、随动、回收；武器外形全程一致 |
| 上挑/下劈 | 各 3 | 蓄力、命中、随动，禁止直接切换到不相关服装或体型 |
| 主动技能 | 至少 7 个关键姿势 | 起势、聚力、第一段、转身、第二段、随动、定锚回收 |
| 冲刺 | 3 个运行姿势 + 残影 | 身体前倾，腿部方向与位移方向一致 |

时间推进以秒和状态进度为准，不依赖渲染帧数。动作切换必须保留位置、缩放和旋转的短时插值；技能结束先进入定锚回收，再回到移动状态，避免单帧抖动。

## 3. 分层顺序

从后向前统一为：

1. 披风后层与技能后层特效；
2. 身体、后腿与服装主体；
3. 武器主体；
4. 腰部遮挡层 `hero_waist_cover.png`；
5. 近侧手臂 `hero_near_arm.png`；
6. 命中闪光、刀光和前层技能特效。

披风和手臂遮罩属于局部覆盖图，不受 `640 × 416` 主画布限制，但必须使用透明背景，并以主画布逻辑原点进行定位。武器必须在同一武器动作组中保持剑身长度、护手、颜色和握点一致；禁止用截断剑身或换装帧补动作。

## 4. 文件命名与导入

- 连续帧：`hero_<state>_<zero_based_index>.png`，例如 `hero_run_0.png`。
- 关键姿势：`hero_<action>_<phase>.png`，例如 `hero_slash_up_windup.png`。
- 图集必须带版本后缀并记录单元尺寸；局部遮罩使用明确的部位名。
- PNG 必须保留 Alpha；禁止白底抠图、JPEG 中转和双线性缩放后重新裁边。
- Godot 导入保持像素风过滤设置一致。新增帧先通过透明边和画布测试，再接入状态机。

## 5. 验收清单

- 60 Hz 与不同窗口尺寸下，待机、跑步、起跳、下落、落地、冲刺、普攻和主动技能各连续观察至少 20 秒。
- 慢放检查脚底是否滑动、服装是否跳变、剑身是否断裂、披风是否穿过身体。
- 连续快速输入攻击与技能，确认状态能回收且没有卡死、抽帧或结束抖动。
- 命中特效关闭后仍能仅凭角色姿势读懂蓄力、命中与收招阶段。
- 自动测试全部通过后，才允许替换正式角色帧。
