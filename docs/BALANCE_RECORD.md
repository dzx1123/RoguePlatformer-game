# 平衡记录

更新时间：2026-09-07
状态：遥测与审查规则已实现；仓库尚无足量真实玩家样本，因此当前不依据模拟数据调整武器强弱。

## 数据来源

`user://run_telemetry.json` 保存最近 60 次已结束路线，记录：

- 起始与结束武器、难度、胜负和路线时长。
- 房间类型、完成时间、承伤、死因和首领击杀时间。
- 强化出现次数、选择次数和选择时武器。
- 中断、手动重开、死亡与胜利等结束原因。

自动审查只产生信号，不自动修改数值。

## 最低样本门槛

| 目标 | 最低样本 | 需要复查的信号 |
| --- | ---: | --- |
| 单把武器 | 8 局 | 使用量低于均分的 60%，或通关率偏离总体 12% 以上 |
| 单项强化 | 12 次出现 | 选择率低于 22%，或高于 56% |
| 单类房间 | 8 间 | 平均耗时高于 42 秒，或死亡率高于 28% |

未达到门槛时只记录体验问题，不标记增强或削弱。

## 调整规则

- 先排查解锁节奏、文案、提示、出现条件和危险预警，再改数值。
- 一次只修改一个主要维度，例如伤害、冷却、敌人配额或预警时间。
- 不同时调整生命、伤害、速度和生成预算。
- 每次调整必须运行对应战斗/构筑测试，并用后续样本复查。
- 真实玩家反馈与遥测冲突时，保留复现步骤并继续采样，不用单局印象覆盖统计。
