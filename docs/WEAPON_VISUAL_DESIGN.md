# 武器外观与动作设计规范

本规范先冻结三种武器的视觉身份与基础持械姿势，再据此重做武器专属动作。当前不导出构建。

## 月弧长剑

- 保留现有模型、配色与单手持剑动作，不改动。
- 定位：均衡、灵活、标准月弧剑术。

## 影织双刃

- 概念图：`weapon_concepts/shadow_twin_blades_idle_concept_v1.png`
- 造型：一长一短两把影色刀刃，共同佩挂在左腰；黑铁刀鞘、暗紫纹路、少量青色晶核，与现有角色配色保持统一。
- 待机：双刃完全入鞘。右手悬在主刀刀柄前，左手稳定刀鞘，身体略微前倾、重心偏低。
- 跑动：刀鞘固定跟随骨盆，不随腿部大幅甩动；左手压住刀鞘，右臂进行小幅反向摆动。
- 跳跃：上升时收膝并压住双鞘；顶点短暂停顿；下落时双脚准备落地，刀鞘始终保持完整轮廓。
- 普攻建议：拔刀、第一斩、反手第二斩、交叉收势、归鞘。快速攻击不能靠单纯加快月弧长剑帧播放，需要独立的拔刀与归鞘关键帧。
- 上劈/下劈：双刀交替形成连续弧线，动作轨迹来自刀身姿态，不额外绘制实体半圆攻击物。
- 主动技能“瞬影连斩”：建议 8–10 帧，加入一次清晰蓄势、三段方向不同的斩击和完整归鞘帧。

## 坠星巨刃

- 唯一造型基准：`weapon_concepts/falling_star_greatblade_rear_carry_concept_v2.png`
- 造型：宽厚暗银巨剑，陨石质感剑脊、暖橙色裂纹、金黑护手与青色核心晶石；长度约为角色肩部至脚下的距离。
- 固定持械方式：以用户确认的低位后托图为唯一基准。双手在后腰附近共同握柄，身体轻微前倾，剑身斜向后下方，待机时剑尖与脚底共用接地线。待机、跑步、跳跃与下落都从这一姿势自然变形，不再使用前持、抬高后托或肩扛姿势。
- 跑动：改为重步快跑。双手持续控制同一握点，剑身保持在身体后下方，剑尖最低像素不得低于脚底基线或穿进平台；肩部随步伐小幅起伏，但头部和脚底不能抖动。
- 跳跃：起跳时将巨剑收近躯干；顶点保持剑身惯性；下落时剑身稍向下压，落地加入一帧腿部与肩部共同缓冲。
- 普攻建议：预备抬剑、身体带动挥落、命中定格、拖剑回收。整体 10–14 帧，伤害高但不能用延长静止帧制造迟缓感。
- 上劈/下劈：上劈由腿、腰、肩共同发力；下劈使用双手过顶砸落，并保留清晰的起手预警。
- 主动技能“裂地坠星”：建议 10–12 帧，包含举剑、短暂蓄力、重砸、地面冲击与拔剑恢复。

## 实现难度与制作边界

- 概念造型：中等难度，已完成首版。
- 游戏内静态换装：中等难度，需要把角色手臂和武器从现有烘焙图中拆分，或为每种武器制作独立完整角色帧。
- 完整动作组：中高难度。两种新武器的手部位置、重心和节奏都不同，不能复用月弧长剑的身体动作后只覆盖一张武器图。
- 推荐方案：为影织双刃与坠星巨刃分别制作完整的待机、跑动、起跳、顶点、下落、落地、前劈、上劈、下劈、主动技能、受击与死亡帧组，再按当前武器切换整套动画资源。
- 关键验收：切换武器时角色体型和脚底锚点不跳变；手掌始终贴合刀柄/刀鞘；跳跃帧中的武器不破损；左右翻转后佩刀方向与握持关系正确。

## 动作重做执行顺序

### 阶段 A：基准与锚点

- [x] 冻结影织双刃腰间收刀造型和坠星巨刃双手后托造型。
- [x] 将两张概念图转制为统一 `416 px` 高 RGBA 动作画布，锁定角色身高、躯干中心、脚底线、双手握点与武器长度；双刃宽 `640 px`，后托巨剑宽 `768 px`。
- [x] 制作两把武器的待机生产基准帧，并通过尺寸、透明边、安全区与脚底基线专项检查。
- [x] 接入运行时武器切换；三种武器按独立 RGBA 画布保持统一人物身高、躯干锚点与脚底线。

### 阶段 B：移动与空中动作

- [x] 影织双刃：按完整人物重绘生成待机与跑步 12 帧；旧版切腿、旋转和拼接帧已全部删除。刀鞘随骨盆移动，不再分割衣摆或腿部。
- [x] 坠星巨刃：按完整人物重绘生成低位后托待机与跑步 12 帧；双手维持同一握点，剑身作为完整轮廓处理。
- [x] 两种武器各自生成起跳、上升、顶点、下落、落地 5 个完整人物姿势，没有覆盖现有月弧长剑武器图。
- [x] 自动检查 60 Hz 跑跳、12 帧循环、动作路径、RGBA、安全边距与快速武器切换；后续仍保留人工慢放验收。

### 阶段 C：方向攻击与技能

- [~] 影织双刃：已接入独立前向、上劈、下劈与技能完整人物关键帧，并采用短拔刀、快速双段斩、提前收刀的独立节奏；后续可继续增加拔刀和归鞘中间画。
- [~] 坠星巨刃：已接入独立前向、上劈、下劈与技能完整人物关键帧，重量来自蓄力、全身驱动、命中停顿感和拖剑回收；后续可继续增加过顶与拔剑中间画。
- [ ] 命中帧与现有攻击判定对齐；下劈命中后的弹起逻辑保持不变，只更换角色动作和武器轨迹。
- [x] 普通攻击剑气使用独立特效层：双刃为错时紫青窄剑气，大剑为宽橙压力弧与延迟冲击线，不烘焙进人物贴图或改变判定。

### 阶段 D：运行时接入与验收

- [x] 建立按当前武器切换的独立动作资源表，月弧长剑、影织双刃、坠星巨刃不再共用同一套完整角色帧。
- [x] 切换武器、受击、落地和攻击取消时回收到当前武器的待机/移动姿势，不能闪回月弧长剑。
- [x] 扩充动作资产与运行时绑定测试，覆盖三种武器的跑步、起跳、下落、落地、前劈、上劈、下劈、冲刺和主动技能。
- [ ] 最后进行慢放、左右翻转、连续输入和 20 秒循环观察；确认无穿模、无破剑、无白边、无锚点抖动后才标记完成。
