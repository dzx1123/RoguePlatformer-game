# 两章人物音效与动作过渡修正

两章正式入口均实例化 scenes/Player.tscn，实际角色脚本为 scripts/player.gd。Journey 已连接动作/语音信号，未复现“所有人物音效完全缺失”；本轮找到了会造成缺音、迟响与动作跳变的具体问题。

- 原合成音效与音乐共用 Music 通道及 0.35 秒生成缓冲；跳跃、冲刺仅靠此通道发声。现在动作合成独立接 SFX，缓冲为 0.04 秒，已有语音、刀声、命中样本沿用原资产和混音参数。该数值为缓冲长度，不等同整机实测端到端延迟。
- Journey 的 RogueSoundscape 原来保持默认 MENU，现按探索、战斗、首领状态调用共用音乐切换。
- 原人物仅插值位置/缩放，整张姿势贴图直接切换；新增 50–75 毫秒的动作边界过渡，覆盖跑动接攻击/技能、收招接移动与换武器。通过现有贴图测得的头部锚点对齐过渡层，避免双头错位。连续跑步帧不叠加过渡，命中停顿同步冻结，受击/死亡/翻面清除旧过渡。
- 非长剑动作贴图原来首次使用时加载；现在入场预热所有武器动作及脚底校准，共享缓存跨章节复用。
- 切武器仍等待正在执行的攻击/技能/冲刺结束，但不再额外等待纯视觉收势时间；技能冷却、伤害与操作规则不变。

验证：chapter_player_output_smoke 在两章、三武器、攻击/技能/跳跃/冲刺共 24 组操作中，以 AudioEffectCapture 读取实际 SFX/Voice 混音样本。音乐静音时 SFX 均有非零输出，攻击及技能语音也有非零输出。此验证检查引擎混音输出，不代表确认了用户扬声器/耳机的硬件输出。

player_pose_transition_smoke 通过真实物理输入检查动作边界、头部对齐、命中停顿、过渡结束恢复单层不透明角色、出招不再加载新贴图，以及动作结束及时切武器。OpenGL 过渡截图已检查。既有三武器步态、动作节奏、武器切换、技能衔接、用户指定音效、共用菜单和跨章继承回归通过。

构建：build/chapter2-player-polish-20260930/EmberForge.exe 与同目录 EmberForge.pck。源码和导出 PCK 的上述音频输出、动作边界专项均需 PASS；不能用单纯 playing=true 代替实际混音检查。

仍需后续完善：素材本身有限的挥砍/收招中间姿势。本轮通过原素材的配准与短过渡减轻硬切，不宣称完整逐帧人物动画或人工整章体验已完成。

## 后续过渡修正（2026-09-30）

- 复现两层普通透明叠加导致过渡中点身体不透明度降至约 0.75。共用人物着色器现在按上一姿势的覆盖区域补偿当前层透明度，重叠身体保持不透明，轮廓外缘继续淡入淡出；跑步素材的白色镂空也参与覆盖计算。
- 头部对齐仅用于当前过渡画面，不再反馈进下一帧位置平滑，避免对齐位移累积成漂移。UV 映射兼容翻面、偏移、缩放及旋转。
- 冲刺/技能残影使用独立材质快照，禁用人物过渡补偿，避免沿用角色实时变化的材质参数。
- 新增 player_transition_render_smoke，以真实 OpenGL 像素检查两种材质的 25%/50%/75% 过渡、非重叠区域和跑步镂空。新增 player_pose_alignment_smoke，检查三武器对齐不反馈，以及转身/受击/死亡取消过渡。
- 新试玩包：build/chapter2-player-transitions-20260930。仍使用两章共用人物、音效和既有游戏规则。
- 验证结果：源码的像素合成、姿势对齐、三武器动作边界、动作节奏、步态、换武器、技能衔接检查均 PASS；新 PCK 的像素合成、动作边界和两章三武器 24 组真实混音输出检查也 PASS。EXE 启动并正常退出。测试日志和过渡截图保存在 test_output。环境仍有系统证书读取和着色器缓存写入警告，未出现脚本/着色器编译错误；实际 OpenGL 输出通过像素检查。
