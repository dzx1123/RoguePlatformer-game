# 开发路线

当前进度：4 / 5 个阶段完成，16 / 19 个路线项完成。

## 01 - 可玩移动原型（已完成）

- 角色移动、跳跃、二段跳
- 冲刺与攻击的基础动作反馈
- 可碰撞的测试房间
- 项目内原创临时视觉，不依赖运行时外部素材

## 02 - 第一套战斗循环（已完成）

- 敌人实体、受击框与攻击判定
- 生命值、受伤无敌帧、击退与死亡
- 一个近战敌人与一个远程敌人

## 03 - 肉鸽一局的结构（已完成）

- 十二种手工房间骨架，并进行镜像、平台扰动和敌人落点扰动
- 每局随机排列并依次加载二十个房间
- 通关房间后出现不重复的三选一强化
- 死亡后清空本局强化并随机重新开局

## 04 - 内容扩展（已完成）

- 三种属性不同的武器，以及各自独立的主动技能
- 精英怪、奖励宝箱、局内商店和多段攻击首领
- 四段敌人生态：史莱姆、哥布林、混合编队与高压混战
- 敌人生命、伤害、速度、侦测和攻击频率随房间累计成长
- 局外星屑结算、武器解锁、选择记录与 JSON 存档

## 05 - 打磨与发布

- 原创像素美术、音效和音乐
- 菜单、设置、键位重绑
- 平衡、性能与导出

## 后续扩展计划（按优先级）

### P0 - 武器与构筑差异化（进行中）

- 三种武器拥有独立的普通攻击节奏、主动技能机制、动作表现与判定
- 将局内强化池扩展到 18 至 24 项，并加入通用、武器专属与稀有度分层
- 增加能够改变打法的联动强化，控制纯数值叠加与成长上限

### P1 - 房间随机性与首领深度

- 保留第 5、10、15、20 房的阶段节点，其余遭遇由带约束的权重系统生成
- 增加事件房、挑战房、风险宝箱和可复现的本局随机种子
- 为首领增加至少三种清晰预警的招式，以及 70% 和 35% 生命阶段变化

### P2 - 平衡、动作与技术结构

- 记录房间耗时、受伤、死亡原因、首领击杀时间、强化选择率和武器通关率
- 以战斗预算和行为变化替代单纯叠加生命、伤害、速度与攻击频率
- 建立角色帧画布、脚底锚点、武器比例和披风层级规范，并持续执行动作审计
- 逐步拆分主流程、HUD、遭遇、强化与房间生成逻辑，避免单一脚本继续膨胀

### P3 - Windows 发布准备

- 增加分辨率、全屏、垂直同步、手柄、分轨音量与减弱闪光/震动选项
- 增加存档临时写入、备份、版本迁移与损坏恢复
- 完善应用图标、版本信息、资源排除、授权记录和正式导出检查
- 增加长时间压力测试、分辨率测试、导出包启动测试与发布检查清单
