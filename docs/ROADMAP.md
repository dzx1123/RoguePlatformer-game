# 开发路线

当前进度：4 / 5 个阶段完成，14 / 17 个路线项完成。

## 01 - 可玩移动原型（已完成）

- 角色移动、跳跃、二段跳
- 冲刺与攻击的基础动作反馈
- 可碰撞的测试房间
- 项目内原创临时视觉，不依赖运行时外部素材

## 02 - 第一套战斗循环（已完成）

- 敌人实体、受击框与攻击判定
- 生命值、受伤无敌帧、击退与死亡
- 一个近战敌人与一个远程敌人

## 03 - 肉鸽一局的结构（已完成）

- 五种手工制作的房间布局
- 每局随机排列并依次加载五个房间
- 通关房间后出现不重复的三选一强化
- 死亡后清空本局强化并随机重新开局

## 04 - 内容扩展（已完成）

- 三种属性不同的武器，以及各自独立的主动技能
- 精英怪、奖励宝箱、局内商店和多段攻击首领
- 局外星屑结算、武器解锁、选择记录与 JSON 存档

## 05 - 打磨与发布

- 原创像素美术、音效和音乐
- 菜单、设置、键位重绑
- 平衡、性能与导出
