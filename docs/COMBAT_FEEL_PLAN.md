# 动作流畅度与打击感计划

状态：第一轮已接入，后续随新帧继续调。  
资产规范：[CHARACTER_ANIMATION_SPEC.md](CHARACTER_ANIMATION_SPEC.md)

## 目标（手感冻结清单）

这些是调参和插帧时要对着看的目标，不是美术任务。

1. 跑步贴地不滑：脚底基线稳定，急停/转身不月步。
2. 技能收招约 0.1 秒内能接冲刺（命中段打完后允许取消）。
3. 命中要有短顿帧；空挥和实砍音量差一截。
4. 普攻命中后可冲刺取消；技能最后一段命中后可冲刺取消。
5. 关掉命中特效后，仍能从姿势读出蓄力、命中、收招。
6. 新帧插入后，状态名和进度点尽量不改，只换贴图和时间。

## 当前实现（不要推倒）

角色不是 `AnimationPlayer` 时间轴，而是 `scripts/player.gd` 状态机：

- 待机、跑步、转身、起跳/下落/落地、普攻、技能、冲刺、受击、死亡
- 跑步按位移推进 8 帧
- 攻击/技能按秒和进度切姿势
- 状态切换插值位置、缩放、旋转
- 技能结束有定锚回收和残影，避免跳回任意跑步帧

画布约定（插帧必须遵守）：

- 完整姿势 `640 × 416`
- 缩放 `0.22`，精灵基础位置 `(0, -15)`
- 地面脚底源图 `Y=402 ± 1 px`
- 新帧先过 `tests/character_frame_spec_smoke.gd` 与 `tests/animation_motion_audit.gd`

## 0.4.1 已做

### 命中顿帧

- 不使用全局 `Engine.time_scale`，避免音效和 UI 一起停。
- 只冻结玩家与敌人的物理推进，姿势停在命中帧。
- 时长：普攻约 `0.050` 秒，技能约 `0.072` 秒，命中首领再加 `0.028` 秒。
- 「减弱闪光与镜头震动」开启时，顿帧缩短到约 35%。
- 已死亡的敌人不再被顿帧拖长死亡动画。

### 取消窗口

| 情况 | 能否冲刺 |
| --- | --- |
| 普攻尚未出判定 | 否 |
| 普攻已出判定（命中进度约 38%） | 是 |
| 技能尚未打完所有段 | 否 |
| 技能最后一段已发出 | 是 |
| 收招混合阶段（remaining 已归零） | 是 |
| 受击硬直中 | 否 |

取消时会正常结束攻击/技能，再进入冲刺无敌。跳跃在攻击中本来就可以，保持不变。

### 空挥与实砍

- 挥刀采样更轻（约 -11 dB）
- 命中采样更重，并保留一层短促的程序冲击

## 后续插帧时怎么接

不要把过渡写死在某一张图的像素上。固定这些接口：

| 接口 | 当前值 | 换帧时 |
| --- | --- | --- |
| 普攻命中进度 | `ATTACK_HIT_PROGRESS = 0.38` | 只在新帧命中姿势对不上时改 |
| 技能命中进度 | 长剑 `0.70`；双刃三段 `0.18 / 0.48 / 0.78`；巨剑 `0.62` | 按新关键帧改数组，不改状态名 |
| 攻击收招混合 | `0.085` 秒 | 新帧若仍抽一下，只加长混合 |
| 技能收招混合 | `0.11` 秒 | 同上 |
| 冲刺收招混合 | `0.065` 秒 | 同上 |

建议流程：

1. 新 PNG 按命名放进 `assets/characters/frames_polished/`
2. 跑帧规格与动作审计测试
3. 把贴图常量接到对应 `VisualState`
4. 实机看 60 Hz 下跑步、起跳、普攻、技能各 20 秒
5. 需要时才改命中进度，不顺手改判定大小
