# 动作与打击感规范

更新时间：2026-09-07
状态：第一轮完成；后续只根据新动作资产或真实试玩反馈调整。

角色动作资产规则见 [CHARACTER_ANIMATION_SPEC.md](CHARACTER_ANIMATION_SPEC.md)。

## 当前基线

- `scripts/player.gd` 使用代码状态机驱动待机、12 帧跑步、转身、起跳/上升/顶点/下落/落地、普攻、技能、冲刺、受击和死亡。
- 跑步循环按实际位移推进，停止时收束到稳定脚位，避免月步和随机停帧。
- 攻击与技能按持续时间和归一化进度切换姿势，不依赖渲染帧率。
- 姿势切换保留短时位置、缩放和旋转混合；技能结束先定锚回收再回到移动。
- 命中特效关闭后，蓄力、命中和收招仍应能从角色姿势辨认。

## 已冻结的手感契约

### 命中顿帧

- 普攻约 `0.050` 秒。
- 技能约 `0.072` 秒。
- 命中首领额外增加约 `0.028` 秒。
- 只冻结相关玩家和敌人物理，不修改全局 `Engine.time_scale`。
- 开启减弱效果后缩短到约 35%，已死亡敌人不被顿帧拖长死亡动画。

### 取消窗口

| 状态 | 冲刺取消 |
| --- | --- |
| 普攻尚未出判定 | 不允许 |
| 普攻判定已发出 | 允许 |
| 多段技能尚未发完 | 不允许 |
| 技能最后一段已发出或进入收招 | 允许 |
| 受击硬直或死亡 | 不允许 |

当前命中进度：普攻 `0.38`；月轮斩 `0.70`；瞬影连斩 `0.18 / 0.48 / 0.78`；裂地坠星 `0.62`。

### 听觉与视觉反馈

- 空挥的刀风显著轻于实砍命中。
- 命中先突出刃击，再错开敌人痛呼，避免同一帧堆叠成噪音。
- 玩家人声高于刃击，刃击高于刀风；技能音色按武器区分。
- 减弱效果会压低顿帧、闪光和镜头震动强度，但不删除关键危险信息。

## 新动作资产接入流程

1. 按规范放入 `assets/characters/frames_polished/`，不覆盖无关姿势。
2. 先运行 `character_frame_spec_smoke.gd` 与 `animation_motion_audit.gd`。
3. 将贴图接入现有 `VisualState`，保持状态名和判定不变。
4. 60 Hz 实机连续观察跑步、转身、起跳、落地、普攻和三武器技能。
5. 只有关键姿势与判定明显错位时才调整命中进度；不要顺手改攻击范围或伤害。
6. 再运行玩家动画、攻击连按、技能释放、上下劈和手柄专项测试。

## 需要证据后再决定的问题

- 三把武器是否需要进一步拆分普攻前摇和后摇。
- 技能是否开放跳跃取消。
- 精英和首领是否需要更明显的受击停顿差异。
- 高频连击的顿帧上限是否影响输入节奏。
- 新落地帧在不同移动速度下是否仍需额外压缩调整。

这些项目没有新帧、60 Hz 实机录像或重复试玩反馈时不进入开发队列。
