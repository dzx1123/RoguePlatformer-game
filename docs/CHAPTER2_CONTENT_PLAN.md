# 第二章内容计划：余烬铸庭

更新：2026-09-16。本文是设计与执行计划，不代表内容已经进入正式游戏。实际实现状态见 [建设清单](CHAPTER2_PROGRESS.md)。

## 范围与体验目标

第一章保留第 1–20 房，第二章规划第 21–40 房。第二章不是把第一章房间复制后加血量：主线体验是识别热区、主动换层、观察冲撞方向，再处理不同敌人的协同压力。以四个五房段落组织教学、组合、变化与收束，每段都有休整或选择，不做连续二十场清怪。

当前仅有两张独立原型地图、三类几何占位敌人与冷却仪式原型。原型长廊已经出现甲虫，用于验证战斗；正式路线仍遵守投掷者第 23 房、守卫第 26 房、甲虫第 31 房首次登场的约定。正式路线接入前，不直接将一局房数改为 40。

## 地图与背景扩充

| 断裂铸桥 | 已有独立原型 | 宽桥教学版、错层组合版、守阵版 | 跳跃落点可见；守卫不能把玩家堵死在唯一落点 |
| 冷却水庭 | 待制作 | 事件、商店、甲虫教学共享骨架，调整布景和通路 | 冷色区与危险热区有形状差异，水面默认仅装饰 |
| 悬链回廊 | 待制作 | 固定平台探索版与停炉版 | 首轮不引入移动平台、摆荡或风场，先验证基础可达性 |
| 环形锻台 | 待制作 | 两入口换层、交替热区、分波战斗 | 任一危险阶段至少有一处可抵达安全站位 |
| 监炉核心 | 待制作 | 首领专用主平台与两侧低台 | 预警不会被前景遮挡，低台不成为无解受击点 |

背景按入口暖铜、桥区深红、冷却区蓝灰、核心白热逐段变化。远景炉塔的位置与规模随推进改变；前景装饰降低对比，危险物保持最高辨识度。先完成灰盒路线与危险覆盖图，再替换正式背景，避免美术完成后大改跳跃距离。

## 敌人与首领方向

普通敌人沿用 [角色锁定](CHAPTER2_CHARACTER_LOCK.md)，首轮不再增加第四种常规怪物。先补现有三种的完整行为、透明动画、受击反馈和组合调度；跨平台追击只在有合法路径时启用，不能瞬移或跳入深坑。首次教学不混入其他新机制。

首领“铸庭监炉者”为设计提案，身份是操纵铸庭核心的重甲监炉者，视觉围绕炉心、重臂与排热背甲展开。第一版不召唤小怪，先保证本体战斗成立。

| 招式 | 起手与应对 | 首轮验收约束 |
| --- | --- | --- |
| 炉锤落击 | 锤臂抬起、地面显示范围；离开范围后反击 | 预警暂定至少 0.90 秒，命中后至少 1 秒恢复；范围在起手后锁定 |
| 炉心抛射 | 逐个标记两处落点；保持移动或换层 | 复用投掷者标记语义；两处爆炸不能覆盖全部安全地面 |
| 排热冲撞 | 朝向锁定、背甲张开；跳开或绕后 | 预警至少 0.80 秒，停止后至少 1.10 秒恢复；不转身追踪已闪避玩家 |
| 核心过载 | 生命降到约一半后单次转阶段，侧区交替排热 | 转阶段先停止攻击并清理旧弹道；不缩短已有预警，不全场同时燃烧 |

数值均为首轮提案，不是现行参数。需要待机、各招式起手/执行/恢复、受击、转阶段与死亡动作；单独定义伤害判定帧，不能用整张贴图边界充当攻击范围。背部加伤仍是待定规则，在方向与反馈验证前不作为通关必需条件。

## 事件、进度与公平性约束

- 冷却仪式正式采用“恢复生命或下一战斗房关闭环境热区”的互斥选择。原型的 25 点治疗仅是当前实现值，正式数值待经济验证；不再同时要求金币支付。早期目录的金币草案待实现时同步移除。
- 铸火代价和熔流试炼都允许拒绝；奖励预览写清代价、作用范围与失败规则，不靠隐藏惩罚制造难度。
- 热区先以原型的 0.85 秒预警、0.55 秒激活、8 点伤害为测试基线；旧目录断桥数值尚不一致，进入数据配置阶段统一，不将设计稿参数误认为运行时已生效。
- 危险提示同时使用轮廓、图案与动作，颜色只是辅助；教学提示沿用设置开关和当前输入设备按键名称。
- 出生点、出口、事件交互位置不受敌人立刻攻击；单向平台、落地叠身、墙边挤压和多敌包围必须回归，不能重新引入怪物与主角上下黏连。
- 正式路线沿用现有一局死亡/继续逻辑；独立原型的本房自动重试是开发便利功能，不直接搬进正式局。继续档记录章节、房间、已领取奖励、事件选择与一次性效果，并避免重进刷奖励。
- 房间目标区分清敌、到达、事件选择和分波完成；休整房不等待不存在的敌人，未激活支路不阻塞出口。
