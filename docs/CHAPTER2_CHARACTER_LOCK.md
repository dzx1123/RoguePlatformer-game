# 第二章敌人角色锁定

三个敌人已锁定为第二章正式敌人，不再改变基础定位。

## 熔火投掷者

- 定位：远程区域控制。
- 核心攻击：抛物线熔火弹，落点提前显示。
- 预警：至少 0.72 秒。
- 玩家应对：移动、换层、冲刺穿过落点。
- 首次出现：第 23 房。

## 铸炉守卫

- 定位：重型近战压迫。
- 核心攻击：蓄力冲撞，撞击后短暂暴露背部。
- 预警：至少 0.80 秒。
- 玩家应对：跳跃、冲刺闪避、绕后反击。
- 首次出现：第 26 房。

## 余烬甲虫

- 定位：高速骚扰和优先级压力。
- 核心攻击：贴近后短暂灼烧，不叠加无限层数。
- 预警：至少 0.45 秒。
- 玩家应对：优先清理或用范围技能处理。
- 首次出现：第 31 房。

## 接入顺序

1. 先制作熔火投掷者的待机、移动、投掷、受击、死亡资源并接入现有远程敌人框架。
2. 再制作铸炉守卫的盾牌、冲撞和背部暴露反馈。
3. 最后制作余烬甲虫的高速移动、灼烧和群体表现。

每个角色进入正式路线前必须通过角色帧规范、攻击预警、命中反馈、生成安全和敌人行为 smoke 测试。
