`D:\Godot\Godot_v4.7.2-stable_win64.exe --headless --editor --path D:\Godot\RoguePlatformer-game --quit-after 3`

## 2. 导出与启动检查

仅在明确需要生成发行包时运行：

`powershell -ExecutionPolicy Bypass -File .\tools\verify_windows_build.ps1`

脚本会：

1. 使用当前项目根目录和 Windows x86_64 preset 导出。
2. 将结果写入 `build/windows-verify/`。
3. 隐藏启动导出的 EXE，等待真实退出码。
4. 检查运行日志是否包含引擎错误。

发布前确认：

- [ ] 导出包来自准备交付的当前提交，不复用旧构建。
- [x] EXE 和 PCK 均存在，启动日志无错误（2026-09-11 当前工作树 Release 验证构建）。
- [ ] 包内不含 `tests/`、`docs/`、`tools/`、开发源素材或旧构建目录。
- [ ] 版本号、构建日期、Git 提交和变更摘要一致。

## 6. 阻断标准

出现下列任一问题不得交付：

- 无法启动、崩溃、卡死或流程无法推进。
- 存档丢失、损坏后无法恢复或版本升级破坏旧档。
- 键盘或手柄关键输入失效，菜单没有可操作焦点。
- HUD、按钮或关键文案越界、遮挡或不可点击。
- 导出包与标注的源码提交、版本或变更摘要不一致。
