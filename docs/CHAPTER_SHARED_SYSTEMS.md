# 章节共用系统约束与本轮核查

用户要求：章节仅增加地图、怪物、背景音乐及明确授权的新技能。角色、操作、UI、选牌、成长、传送和整局规则必须沿用第一章，不以开发试玩为理由另建玩家界面。

本轮修正：第一章原选牌构建、卡面内容/样式、悬停动画和入场动画提取为 RewardChoiceView，两章引用同一组件。第二章普通强化与试炼奖励使用 RunUpgradeService 三选一池和原升级目录，去除玩家入口固定二选一。商店沿用同一服务的三商品、金币不足禁用与交互离开；现有事件/路线选择也由共用卡牌显示。原型切片保留内部逻辑供旧测试使用，主菜单和正式衔接均使用 Journey 共用卡牌。

验证：第一章 reward_layer_smoke 改用全旅程结算入口与 40 房预期后通过（旧测试还在第一章结束时要求结算）；第二章三武器选牌生效、防重复领取、商店不足禁用通过。检查点在领奖换房时按原流程写入。

仍需逐项对齐的架构差异，不能宣称已全部统一：Journey 暂停菜单目前仍是简化版本，未完整复用第一章设置/构筑入口；章节专属事件数据和奖励触发时机仍由章节脚本编排；第二章音乐/战斗音效接线还需核查。后续开发优先合并这些公共流程，再扩展地图怪物，禁止继续新增平行 UI。
