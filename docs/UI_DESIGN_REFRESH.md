# 《月蚀回廊》UI 视觉刷新设计说明（0.4.x → 视觉统一）

状态：设计稿（实现前）  
作者：demon（监工）  
约束：优先 **纯代码 StyleBoxFlat / Label / ColorRect**，不依赖新原画；不推翻已统一的奖励层骨架；遵守手柄焦点与「减弱动效」；不借机大拆 `main.gd`（抽 token 辅助函数可以）。

画布：`1280 × 840`（现有 `DISPLAY_SIZE`）。安全区：四边各 **48px** 内放可交互与关键信息（为后续 HUD 缩放留余量）。

---

## 1. 诊断（为什么现在「丑」）

1. **中英混排抢戏**：奖励层 kicker 全大写英文（`LUNAR RELIC` / `ASTRAL MARKET`），标题又是中文 → 像未本地化原型，不是月蚀世界观。
2. **层级靠「深色方块 + 亮描边」堆出来**：面板、卡片、toast、底栏用了相近的青黑底，稀有度/商店/事件只换描边色，**形状与字号节奏几乎一样**。
3. **信息噪音**：底栏三段 + 顶栏状态 + 房间号 + 英文 kicker + 符号◇✦◐，战斗时视线找不到「血 / 技能 / 危险」。
4. **焦点与主次弱**：入口按钮、难度卡、选牌卡都是「描边矩形」，主 CTA（开始/继续）不够「唯一发光」。
5. **残留原型感**：`Main.tscn` 仍有 `ROGUE PLATFORMER / PROTOTYPE 01`；部分提示格式不统一（`E / RB` vs 纯键名）。
6. **确认条（RewardFeedback）像系统弹窗**：顶栏居中大卡片 + 全屏淡色 veil，风险开箱时尤其破坏战斗开场（审查 A2）。

已有优点（保留）：月夜青金调、奖励层四模式骨架、稀有度描边方向、传送门仪式、三段底栏分区概念、减弱动效开关。

---

## 2. 设计原则（给实现用的硬规则）

1. **中文优先，英文降级**：玩家可见主文案一律中文；英文只允许作为极小「符文装饰」（字号 ≤ 11、透明度 ≤ 0.35），或完全去掉。
2. **一屏一个主焦点**：入口=继续/开始；选牌=当前焦点卡；战斗 HUD=血条；胜利=「再来一局」。
3. **颜色叙事固定**：
   - 探索/强化（月弧青）
   - 商店（星尘金）
   - 事件（月蚀紫）
   - 胜利/安全（翠辉绿）
   - 危险/风险（血月红）— **仅用于危险，不用于普通确认**
4. **少描边、多层次**：底用低对比面，强调用「顶栏色条 + 内侧高光」而不是四边同粗 border。
5. **战斗中 UI 让路**：战斗时确认条禁止全屏 veil；toast 改为底栏上方细条（见 §5.5）。
6. **动效服从减弱选项**：入场位移 ≤ 12px；减弱时仅淡入淡出。

### 3.2 字号阶梯（px）

| 级别 | Size | 用途 |
| --- | --- | --- |
| Display | 48–54 | 仅标题「月蚀回廊」 |
| Title | 28–32 | 面板大标题 |
| Headline | 20–22 | 卡片名、主按钮 |
| Body | 15–16 | 说明 |
| Caption | 12–13 | 提示、手柄图例 |
| Micro | 10–11 | 装饰英文（若保留） |

### 3.3 圆角与间距

- 面板大圆角：`16`
- 卡片圆角：`12`
- 小芯片/toast：`10`
- 基准间距：`8`；区块：`16`；面板内边距：`24`
- 三卡间距：`20`；卡片尺寸建议：`320 × 420`（现有可微调，保持三列居中）

### 3.4 阴影

- 模态面板：`shadow_size 18 / offset (0, 10) / α 0.55`
- 焦点卡：额外外发光用 `accent` @ 0.35，**不要**再加粗 border 到 4px+

## 4. 文案规范（立刻能减「丑」）

| 场景 | 旧（禁） | 新（用） |
| --- | --- | --- |
| 强化 kicker | `LUNAR RELIC · CHOOSE ONE` | `月弧遗物 · 三选一` |
| 商店 | `ASTRAL MARKET · PURCHASE ONE` | `星尘旅商 · 购入一项` |
| 事件 | `ECLIPSE OMEN · …` | `月蚀奇遇 · 皆有代价` |
| 胜利 | `ROUTE SEALED · …` | `月蚀封印 · 路线已净化` |
| 确认购买 | `TRANSACTION COMPLETE` | `购入完成` |
| 开箱 | `MOONLIT CACHE · …` | `月匣开启` |
| 风险开战 | 全屏英文 toast | **不要 toast**；状态栏：`伏兵来袭——肃清后领取报酬` |

手柄提示统一格式：`键盘键 · 手柄键`，例：`E · RB`，字号 Caption，颜色 `text_secondary`。

## 5. 分屏设计

### 5.1 标题页（Entry）

**布局**
- 背景：保留月夜圣所图；底部加 **高度 280** 的渐变遮罩（`bg_deep` 0→0.85），保证按钮可读。
- 标题「月蚀回廊」Display + 副标题一行 Caption：`二十房月桥 · 肉鸽动作`
- 主按钮区垂直居中偏下：若有继续 → **继续旅程**（主 CTA，金描边+内填微光）；**开启新局**（次级）；设置 / 退出（文字按钮或瘦按钮）。
- 局外进度摘要：底边安全区内横条，不要大红大紫；图标化星屑数字即可。

**禁止**：标题页再叠战斗 HUD；原型英文大标题。

### 5.2 难度页

- 三张难度卡横排，**当前焦点卡**上移 6px + `accent_moon` 顶条。
- 每卡结构：难度名（Headline） / 一句话后果（Body，左对齐） / 底部小字成长节奏（Caption）。
- 返回用明确「返回」按钮，不要只靠取消键沉默。

### 5.3 战斗 HUD

保持左生命 / 中技能 / 右武器，但：
- 底栏高度压到 **96px**；背景用 `bg_panel` @ 0.92，**顶边 2px `accent_moon` 细线**，不要厚边框盒子套盒子。
- 生命：实心条 + 短数字 `当前/最大`；受击时条闪 `accent_risk` 120ms（减弱动效则只改色一帧）。
- 房间号/种子：左上 Caption，单行 `第 N/20 房 · S####`，不要又粗又长的面板。
- 状态提示（`_set_status`）：改到 **底栏上方 8px** 的单行芯片，最多 28 字，3 秒淡出；不要顶屏横幅。

### 5.4 奖励层（强化 / 商店 / 事件 / 胜利）同一骨架

共用：暗幕 `bg_veil` + 中央面板（宽 1120，高随内容）。

**顶区（所有模式同一节奏）**
1. 顶色条 3px（模式 accent）
2. Kicker（中文，Caption，accent 色）
3. 标题（Title，`text_primary`）
4. 副提示（Caption，`text_secondary`，含输入图例）

**选牌三卡**
- 顶条颜色 = 稀有度 token
- 名称 Headline；描述 Body 最多 3 行；底角显示「通用/专属」芯片
- 焦点：顶条加亮 + 外发光；未焦点亮度 0.78
- 入场：错峰 40ms，位移 8px（减弱：仅 α）

**商店**：价格用 `accent_gold` 大号数字贴卡片底；金币不足卡 `text_disabled` + 禁止确认。

**事件**：标题区加一句「代价预览」；确认后 toast 必须显示**实际**数值（与审查 A1 一致）。

**胜利**：三统计卡保留；底部主 CTA 按钮「再来一局」（焦点默认落此）；次文案「按 R · View 也可重开」。

### 5.5 奖励确认条（RewardFeedback）重设计

| 状态 | 行为 |
| --- | --- |
| 选牌/商店/事件结束后（非战斗） | 可用中型 toast，**无全屏 veil**，或 veil α≤0.10 |
| 普通开箱（即将进门） | 底栏上方细条：高 56，宽 520，居中 |
| 风险开箱开战 | **禁止** present；只用状态芯片 |
| 风险肃清发奖 | 细条 toast，数字用实际恢复 |

视觉：左 4px accent 竖条 + 标题一行 + 明细一行；圆角 10；阴影轻。

### 5.6 暂停 / 设置

- 暂停：窄面板（宽 420）居中，列表式按钮，主「继续」焦点。
- 设置：分组标题 Caption 大写间距；滑条与开关对齐到同一右栏；开关开=accent_moon 填充。

### 5.7 死亡复盘

- 全屏暗幕；中央「陨落」Title + 死因 Body
- 三列：房间 / 承伤来源 / 剩余命数——与胜利卡同结构但描边 `accent_risk`
- 主按钮「再次挑战」；次「返回标题」

## 8. 成功标准（玩家观感）

- 5 秒内能看出「这是中文月蚀动作肉鸽」，不是英文原型壳
- 战斗时屏幕上半空旷，信息沉底
- 选牌/商店/事件靠颜色叙事可辨，不靠读英文 kicker
- 手柄焦点始终有一道「顶条/外发光」唯一高亮
