# P7 UI 与房间转场打磨清单

状态：进行中。此清单按玩家从“进入游戏”到“清房进入下一房”的体验顺序维护。

## 已识别的问题

1. 首屏只有深色遮罩，缺少独立背景、视觉焦点与品牌氛围。
2. 开始、设置和难度选择共用单薄按钮，主次关系和键鼠/手柄焦点不够清楚。
3. 三选一卡片直接出现，缺少奖励感、稀有度层级、悬停与确认前的视觉预期。
4. 清房后直接进入选牌/下一房，缺少“战斗结束 → 离开房间”的仪式感和可控节奏。（已改为月蚀传送门；走近后按 E / RB 进入。）
5. HUD 的房间信息、状态提示、底部战斗栏仍需进一步统一边框、留白与信息优先级。
6. 菜单、选牌、宝箱和传送门需要统一键盘/手柄提示格式，并在手柄断连后继续可读。
7. 宽屏、窗口缩放、色盲/字号/HUD 缩放下的 UI 安全区还需要实机验收。

## 本轮已完成

- [x] 首屏接入独立的原创月夜圣所背景，并使用半透明框体、饰线和分层文字建立焦点。
- [x] 开始、设置、退出和三档难度改为有主次、边框、悬停与手柄焦点反馈的卡片式控件。
- [x] 强化选择页改为带稀有度描边、悬停抬升、暗幕淡入和错峰入场的三张奖励卡。
- [x] 清房后生成“月蚀之门”光柱、悬浮粒子与走近后按 E / RB 进入的气泡；进入后才展示奖励选择。
- [x] 新增流程与视觉截图测试入口，覆盖首屏、难度、传送门和选牌四种状态。
