## 已识别的问题（历史）

1. 首屏只有深色遮罩，缺少独立背景、视觉焦点与品牌氛围。
2. 开始、设置和难度选择共用单薄按钮，主次关系和键鼠/手柄焦点不够清楚。
3. 三选一卡片直接出现，缺少奖励感、稀有度层级、悬停与确认前的视觉预期。
4. 清房后直接进入选牌/下一房，缺少仪式感。（已改为月蚀传送门）
5. HUD 房间信息、状态提示、底部战斗栏需统一。（U3 已签收）
6. 菜单、选牌、宝箱和传送门需统一键鼠/手柄提示。
7. 宽屏、窗口缩放、色盲/字号/HUD 缩放下的 UI 安全区需实机验收。
